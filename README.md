# Minute Voice

Android 8.0 이상용 한국어 음성 알람 앱입니다. 알람 여러 개를 각각 설정하고, **안내 간격은 항상 1분**입니다.

## 사용 방법

1. APK를 휴대폰에 설치합니다.
2. 큰 시각 표시를 눌러 알람 시각을 지정합니다. 새 알람의 기본값은 등록 화면을 연 현재 시각(시·분)입니다. 알람 제목은 선택 사항이며 저장 후 앱을 다시 열어도 유지됩니다.
3. 알람 전 안내 최대시간과 알람 후 안내 최대시간을 각각 숫자로 입력합니다(0~180분). 기본값은 전 20분 / 후 10분입니다. 0으로 지정한 쪽은 안내하지 않으며, 지정 시각의 안내는 항상 있습니다.
4. 반복 알람을 켜거나 끕니다. 켜면 선택 요일마다 반복하고, 끄면 다음 한 번의 안내 구간만 실행합니다.
5. 새 알람은 ‘오늘 날씨 알려주기’가 켜져 있습니다. ‘현재 도시 포함’을 선택하거나 도시를 검색해 여러 지역을 추가할 수 있습니다. 서울은 검색해서 추가했을 때만 읽습니다. 추가한 도시는 ×로 삭제합니다. 뉴스는 연합뉴스·네이트 뉴스 중에서 고릅니다.
6. 화면 맨 위의 ‘저장’을 누릅니다. 정확한 알람 권한을 요청하면 허용한 뒤 다시 저장합니다. 알림 권한도 허용하면 음성 안내 알림에서 알람을 끌 수 있습니다.

오전 7시, 전 20분 / 후 10분 설정 예:

| 시각 | 음성 |
| --- | --- |
| 06:40 | 알림을 시작합니다. 7시 20분 전입니다 |
| 06:41 | 7시 19분 전입니다 |
| … | 매분 안내 |
| 06:59 | 7시 1분 전입니다 |
| 07:00 | 7시입니다. 알람 시간입니다 |
| 07:01 | 7시 1분 지났습니다 |
| … | 매분 안내 |
| 07:10 | 7시 10분 지났습니다. 알림을 종료합니다. |

제목을 ‘출근’으로 설정하면 “출근 20분 남았습니다”, “출근 시간입니다”, “출근 1분 지났습니다”처럼 안내합니다. 제목이 없거나 공백만 있으면 위 표처럼 지정 시각으로 안내합니다. 미리듣기와 안내 예시에도 입력한 제목이 반영됩니다.

첫 실제 음성 안내 앞에는 “알림을 시작합니다”, 마지막 안내 뒤에는 “알림을 종료합니다”를 한 번씩 읽습니다. 선택한 알람 소리가 마지막 안내에서 재생되는 경우 종료 문구는 소리가 끝난 다음에 읽습니다. 알림의 중지 버튼을 누르면 음성을 즉시 멈춥니다.

선택한 요일마다 반복을 끄면 한 번의 안내 구간을 마친 뒤 해제됩니다. 이미 오늘의 알람 시각이 지났으면 내일로 예약합니다. 안내 시작 시각이 지났지만 알람 시각 전이라면 다음 분부터 안내합니다. 편집한 설정은 저장 버튼을 눌러야 적용됩니다.

## 구현

- Java / Android 기본 UI, 외부 런타임 라이브러리 없음
- `AlarmManager.setAlarmClock()`으로 매분 다음 안내를 정확한 알람으로 예약
- 각 음성 안내는 mediaPlayback 포그라운드 서비스에서 한국어 TTS로 재생
- 알람 오디오 스트림 사용, 재생 중 짧은 wake lock과 오디오 포커스 사용
- 재부팅 / 앱 업데이트 시 저장된 예약 복원, 시각·시간대 변경 시 재계산
- 1분 이상 늦게 전달된 안내는 생략하여 지난 안내가 몰아서 재생되는 현상 방지
- 선택한 날씨·뉴스 안내에만 인터넷 사용. 음성 엔진에 따라 한국어 음성의 별도 설치가 필요할 수 있음

Android의 [정확한 알람 문서](https://developer.android.com/develop/background-work/services/alarms)와 [백그라운드 서비스 실행 조건](https://developer.android.com/develop/background-work/services/fgs/restrictions-bg-start)에 따라 구현했습니다.

휴대폰이 꺼져 있거나 앱을 강제 종료한 상태에서는 안내할 수 없습니다. 일부 제조사의 배터리 제한 및 방해 금지 설정은 실제 기기에서 확인해야 합니다. 정확한 알람 권한이 취소되면 다시 허용한 후 알람을 저장해 주세요.

## 빌드 / 검사

JDK 17, Android SDK 36:

```sh
./gradlew :app:assembleDebug :app:lintDebug
mkdir -p /tmp/minutevoice-tests
javac -d /tmp/minutevoice-tests app/src/main/java/kr/co/minutevoice/AlarmLogic.java app/src/main/java/kr/co/minutevoice/KoreanHolidays.java tests/AlarmLogicTest.java
java -cp /tmp/minutevoice-tests kr.co.minutevoice.AlarmLogicTest
```

APK: `app/build/outputs/apk/debug/app-debug.apk`

실기기 확인 권장: 현재 시각 3분 후로 알람을 설정하고 전 2분 / 후 2분으로 저장한 다음 화면을 끕니다. 다섯 번의 안내(2분 전, 1분 전, 지정 시각, 1분 후, 2분 후)를 확인합니다. 재부팅 후 복원, 반복 끄기, 알람 해제도 확인합니다.

## 정식 배포 빌드

현재 버전: **1.16.0** (`versionCode 34`). 알람 진행 중 알림에 저장된 현재 도시의 날씨와 기온을 표시합니다. 위치가 저장된 알람은 음성 날씨 옵션과 관계없이 현재 날씨를 조회하고, 진행 중 새 값이 들어오면 같은 알림을 갱신합니다.

```sh
./gradlew :app:exportReleaseApk :app:exportReleaseBundle :app:lintRelease
```

결과: `dist/MinuteVoice_v1.16.0.apk` (직접 설치용)와 `dist/MinuteVoice_v1.16.0.aab` (Google Play 제출용). 모두 릴리스 키로 서명했습니다.

배포 서명 키는 `.signing/minutevoice-release.jks`, 서명 설정은 `release-signing.properties`에 있으며 Git에서 제외됩니다. 후속 업데이트에 같은 서명이 필요하므로 두 파일을 안전하게 백업해야 합니다. 기존 디버그 APK와는 서명이 달라 디버그 앱을 먼저 삭제해야 설치할 수 있으며, 삭제 시 기존 알람 설정도 지워집니다.

## 안내 범위 입력 (v1.13.1)

알람 전 / 알람 후 입력란에 0~180 사이의 숫자를 입력합니다. 0은 해당 방향의 안내를 끕니다. 기존 저장값은 유지되며, 범위를 벗어나거나 비어 있는 값은 저장할 수 없습니다.


## 앱 소개 (v1.2.2)

목록과 등록·수정 화면의 ⋮ 메뉴에서 ‘앱 소개’를 누르면 앱 이름과 설치된 앱의 버전명이 표시됩니다. 버전명은 빌드 설정에서 자동으로 가져오므로 새 배포본에도 반영됩니다.


## 주말 요일 색상 (v1.2.3)

일요일과 토요일을 색으로 구분합니다. 현재 배색은 아래 v1.6.1 설명을 따릅니다.


## 여러 알람 (v1.3.0)

첫 화면에서 저장한 알람을 시각순으로 볼 수 있습니다. 지정 시각, 제목, 요일, 개별 활성화 스위치를 표시하며 모든 요일은 ‘매일’로 표시합니다. ‘알람 추가’로 새 알람을 만들고, 목록 항목을 누르면 수정합니다. 삭제는 확인 후 적용합니다. 저장은 해당 알람을 켜고 목록으로 돌아갑니다.

기존 단일 알람은 첫 실행 또는 업데이트 후 예약 복원 시 자동 이전합니다. 알람별 제목·요일·전후 안내 범위·공휴일 제외·반복 설정 및 활성화 상태를 독립적으로 보관합니다. 같은 시각에 도착한 안내는 순서대로 읽습니다. 하나를 끄거나 삭제해도 다른 알람의 예약과 음성은 유지합니다.

검증: 시간·요일 계산 3,587개 단언 통과. Android 15 에뮬레이터에서 기존 설정 이전, 중복 없는 ID, 알람별 예약·비활성화·삭제·복원 16개 단언 및 목록/추가/활성화/수정 화면 UI 검증 통과. 실제 휴대폰의 스피커 출력 및 절전 상태 장시간 동작은 별도 확인이 필요합니다.

계측 테스트는 테스트 기기의 알람 데이터를 초기화하므로 개인 데이터가 없는 에뮬레이터에서만 실행합니다. `MultiAlarmTestRunner`는 `:app:assembleDebugAndroidTest`로 빌드하며 UI 검증 스크립트는 `tests/ui_multi.py`입니다.


## 등록 화면 정리 (v1.3.1)

새 알람의 기본 시각은 현재 시각이며, 기존 알람 수정 시에는 저장된 시각을 유지합니다. 시각 아래에 제목 등록 입력란을 배치하고 ‘반복 알람’ 스위치를 요일 설정 위에 표시합니다. ‘이렇게 안내해요’와 미리듣기 영역은 제거했습니다. 화면 회전 시 작성 중인 설정도 유지합니다. 현재 분으로 바로 저장하면 이미 지난 시각이므로 선택 요일 중 다음 해당 시각으로 예약됩니다.


## 안내 중 알림 표시 (v1.3.2)

음성 안내가 시작되면 알림창에 같은 문구를 즉시 표시하고, 재생을 마치면 제거합니다. 여러 알람이 대기 중이면 현재 재생 중인 문구로 갱신합니다. 긴 문구는 펼친 알림에서 확인할 수 있고 ‘이 알람 끄기’로 해당 알람을 해제합니다. 휴대폰 설정에서 앱 알림을 허용해야 표시됩니다. Android 12 이상의 표시 지연을 피하기 위해 [즉시 표시 설정](https://developer.android.com/reference/android/app/Notification.Builder#setForegroundServiceBehavior(int))을 적용합니다.


## 알림에서 알람 중지 (v1.3.3)

음성 안내 중 알림을 펼쳐 ‘알람 중지’를 누르면 해당 알람의 현재 음성과 이번 회차의 남은 안내를 중지합니다. 반복 알람은 선택한 요일과 공휴일 제외 조건에 맞는 다음 회차를 유지하며, 한 번 알람은 꺼집니다. 다른 알람은 계속 동작합니다. 목록의 활성화 스위치를 끄면 이후 반복까지 해제됩니다.


## 알람 소리 / 노래 선택 (v1.4.0)

등록·수정 화면의 ‘소리 목록 / 노래 검색’에서 기본 알람음 또는 파일 선택기의 검색 기능으로 휴대폰 노래를 선택합니다. 온라인 음악 서비스 검색은 포함하지 않습니다. 기본값은 기존과 동일한 ‘음성 안내만’입니다. 선택은 알람별로 저장되며 파일 읽기 권한을 유지합니다. 파일을 이동·삭제하거나 제공 앱의 권한이 바뀌면 다시 선택해야 합니다.

지정 시각의 음성 안내 뒤 선택한 소리를 한 번, 최대 30초 재생합니다. 전후 매분 안내는 음성으로 계속하고 재생 중 알림의 ‘알람 중지’로 멈출 수 있습니다. 여러 알람이 겹치면 순서대로 재생합니다.


## 안내 구간 동안 알림 유지 (v1.4.1)

첫 안내부터 마지막 안내 재생 완료까지 알람별 ‘알람 진행 중’ 알림을 유지하며 매분 문구를 갱신합니다. 음성 사이에도 ‘알람 중지’를 누를 수 있습니다. 중지·비활성화·삭제하면 해당 알림을 제거합니다. 음성 재생 중에는 재생 서비스 알림이 함께 표시될 수 있습니다. 서비스가 예기치 않게 종료되더라도 남은 알림은 마지막 안내 예정 시각으로부터 최대 1분 뒤 자동 만료됩니다.


## 목록 및 등록 화면 (v1.4.2)

목록에 ‘알람 전 N분 · 알람 후 N분’을 표시하고 켜짐/꺼짐 문구는 제거했습니다. 활성화 스위치는 유지합니다. 새 알람은 공휴일 제외가 기본으로 켜지며 기존 알람 설정은 유지합니다. 등록 화면 맨 위의 저장 버튼은 하단 저장 버튼과 동일하게 검증 후 저장·활성화하고 목록으로 돌아갑니다.


## 상단 버튼 고정 (v1.4.3)

등록·수정 화면의 ‘알람 목록’과 ‘저장’을 스크롤 영역 밖의 상단 바에 배치했습니다. 설정 내용을 스크롤해도 두 버튼은 상단에 유지됩니다.


## 파란 알람 스타일 (v1.5.0)

첨부 참고 화면을 바탕으로 파란 배경, 얇고 큰 시각, 분홍 스위치와 하단 + 버튼을 적용했습니다. 각 목록의 화살표로 수정·삭제를 펼칩니다. 기존 요일과 전후 안내 분 표시는 유지합니다. 등록 화면은 요청한 반복·요일·공휴일·알람소리 설명 및 하단 저장/끄기 버튼을 제거하고 상단 고정 저장만 유지합니다. 앱 소개는 목록과 등록 화면의 ⋮ 메뉴에 있습니다.

아이콘 참고 검색: https://github.com/google/material-design-icons . 배포 아이콘은 이 프로젝트에서 직접 작성한 Android 벡터이며 외부 이미지 파일은 포함하지 않습니다.


## 전체 테마 (v1.6.0)

⋮ → 테마에서 클래식 블루, 미드나이트, 클린 화이트, 세이지, 라벤더를 선택합니다. 기존 스타일은 기본값으로 유지하며 선택은 모든 알람 목록/등록/수정 화면과 기본 입력 위젯에 공통 저장됩니다. 등록 중 테마를 바꿔도 입력값을 유지합니다. 카드와 화면 배경의 명도 차이, 20dp 간격, 얇은 내부 구분선을 적용해 반복/요일/공휴일을 자연스럽게 분리했습니다. 외부 파일 선택기와 시스템 알림의 외형은 안드로이드 설정을 따릅니다.

## 요일 버튼 배색 (v1.6.1)

등록·수정 화면의 일요일은 분홍, 월~금은 연녹색, 토요일은 하늘색으로 구분합니다. 선택 상태는 더 선명한 배경과 2dp 윤곽선으로 표시합니다. 선택 해제 상태는 밝은 테마에서 연한 색, 블루·블랙 테마에서 어두운 색을 사용합니다. 모든 버튼의 글자와 배경 대비는 4.9:1 이상입니다.

## 크로노 테마 (v1.7.0)

첨부된 알람 화면을 참고해 남색 배경, 짙은 둥근 카드, 굵은 시각, 연보라 버튼과 스위치를 적용했습니다. 목록 위에는 활성화된 알람 중 다음 시각과 남은 시간을 표시합니다. 목록의 알람은 기존처럼 개별 켜기·끄기, 수정, 삭제할 수 있습니다. 등록·수정 화면에도 같은 남색/연보라 색과 둥근 카드·버튼을 적용합니다. ⋮ → 테마에서 ‘크로노 · 남색과 연보라’를 선택합니다.

## 테마별 요일 배색 (v1.7.1)

일요일 분홍, 평일 녹색, 토요일 파랑의 의미는 유지하면서 테마마다 색조와 밝기를 맞췄습니다. 블루·미드나이트·크로노는 해제 버튼을 어둡게, 화이트·세이지·라벤더는 연하게 표시합니다. 선택한 요일은 밝은 배경과 윤곽선으로 구분합니다. 크로노 테마의 목록 요일 칩에도 같은 테마 색을 적용합니다. 전체 36개 글자/배경 조합의 대비는 최소 5.1:1입니다.

## Google Play 제출 준비 (v1.8.0)

Android 16(API 36)을 타겟으로 빌드합니다. 앱의 ⋮ 메뉴에서 개인정보처리방침을 볼 수 있습니다. `play-store/`에 한국어 스토어 등록 문안, 공개 게시용 개인정보처리방침 HTML, 앱 아이콘, 기능 그래픽, 실제 화면 스크린샷을 준비합니다. 공개 개인정보처리방침 URL 및 개발자 계정의 최종 설정은 제출 전에 필요합니다.

## 날씨·뉴스 안내 (v1.9.0)

등록·수정 화면에서 알람별로 ‘오늘 날씨 알려주기’와 ‘오늘의 주요 뉴스 듣기’를 선택합니다. 날씨는 등록 시 저장한 현재 위치의 Open-Meteo 일별 예보(하늘 상태·최저/최고 기온)를 사용하며, 첫 사전 안내 5분 전에 받아 매분 사전 음성 안내와 지정 시각 안내에 포함합니다. 뉴스는 지정 시각 1시간 전에 SBS 뉴스 한국어 주요 뉴스 RSS의 기사 제목 최대 3개를 받아 지정 시각에 한 번 읽습니다. 인터넷 연결 실패 시 기본 시간 안내는 정상적으로 계속하며 실패한 정보는 읽지 않습니다.

위치 권한은 날씨 옵션을 켰을 때만 요청합니다. 위치 좌표가 예보 제공자에 전송되므로 개인정보처리방침과 Play 데이터 보안 설문을 v1.9.0 기준으로 다시 검토해야 합니다. [Open-Meteo 무료 API](https://open-meteo.com/en/terms)와 [SBS 뉴스 RSS](https://news.sbs.co.kr/news/rss.do?cooper=SBSNEWS&plink=SITEMAP)는 비상업적 이용 조건이 있으므로 광고·유료화 전에 이용 허락 또는 공급원 변경이 필요합니다.

## 서울·현지 도시 날씨 및 현재 기온 (v1.10.0)

등록 시 선택한 위치의 도시 이름을 확인합니다. 서울이면 서울 날씨만 읽고, 서울 밖이면 서울과 현지 도시의 날씨를 함께 읽습니다. 각 지역의 현재 기온, 하늘 상태, 당일 최저·최고 기온을 안내합니다. 날씨는 첫 사전 안내 전에 가져오고 사전 안내 구간 동안 약 10분마다 갱신합니다. 도시 이름을 확인할 수 없으면 ‘현재 위치’로 표시하고 두 지역의 날씨를 안내합니다. Android 주소 변환 서비스가 도시 이름 확인에 사용될 수 있습니다.

## 도시 선택 및 안내 순서 (v1.11.0)

v1.11.0에서는 새 알람의 날씨 안내가 기본으로 켜졌고, 현재 도시 선택과 도시 검색·추가·삭제를 도입했습니다. 이 버전까지는 서울을 자동으로 포함했습니다. 도시 검색 결과에서 지역·국가를 확인해 최대 8개를 추가할 수 있습니다. 선택한 도시와 순서는 알람별로 저장됩니다. 등록을 취소하면 변경 사항은 적용되지 않습니다.

날씨가 준비된 경우 각 사전 안내에서 남은 시간을 읽고 선택한 도시의 날씨를 읽은 뒤 남은 시간을 다시 읽습니다. 지정 시각에 날씨·뉴스를 읽을 때는 알람 시각 문구를 앞뒤로 읽습니다. 날씨·뉴스 데이터가 없으면 기존 시간 안내만 재생합니다.

## 도시 직접 선택 및 뉴스 출처 (v1.12.0)

서울을 자동으로 포함하지 않습니다. 현재 도시 포함을 켰다면 현재 도시만 자동 선택하고, 서울을 비롯한 다른 도시는 검색해서 추가해야 읽습니다. 날씨 읽기를 켠 채 현재 도시를 제외하려면 최소 한 도시를 추가해야 합니다. 오늘의 주요 뉴스를 켜면 연합뉴스 최신기사 RSS 또는 네이트 뉴스 관심뉴스 랭킹 중 한 곳을 알람별로 선택할 수 있습니다. 뉴스 설명 문구는 등록 화면에서 제거했습니다. 네이트의 페이지 구조가 바뀌면 제목 추출에 영향을 줄 수 있습니다.

## 알림 중복 제거 (v1.12.1)

알람 구간 알림과 음성 재생 서비스가 같은 알림 ID를 사용합니다. 알람별 상시 알림은 제목과 시각을 표시하고 알람 중지 동작을 유지합니다. 매분 안내가 울려도 별도 알림을 만들거나 알림 내용을 분 단위 문구로 갱신하지 않습니다.

## 주요뉴스 추출 (v1.12.2)

연합뉴스는 공식 ‘주요뉴스’ 목록, 네이트 뉴스는 뉴스 홈의 메인 이슈에서 상위 기사 제목 3개를 읽습니다. 기존의 연합뉴스 최신기사 RSS와 네이트 관심뉴스 랭킹은 더 이상 사용하지 않습니다. 주요뉴스 목록을 읽지 못하면 뉴스 안내를 건너뛰고 알람 시간 안내는 계속합니다.

## 뉴스 건수 및 읽기 개수 (v1.15.0)

뉴스 기능을 켜면 다음 뉴스·연합뉴스·네이트 뉴스의 주요뉴스 건수를 그 시점에 각각 조회해 표시합니다. 껐다가 다시 켜면 새로 조회합니다. 알람별로 읽어줄 뉴스 개수를 0~100 사이에서 입력할 수 있으며 0은 전체입니다. 알람 1시간 전에 새로고침한 뉴스의 전체 건수와 실제 읽을 건수를 음성으로 먼저 안내합니다. 긴 뉴스 묶음은 나누어 읽어 TTS 입력 길이 제한으로 누락되지 않게 합니다. 기사 수는 뉴스 출처의 업데이트에 따라 달라집니다.

## 진행 중 알림의 현재 날씨 (v1.16.0)

알람 진행 중 알림에는 알람 제목·시각과 함께 저장된 현재 도시의 날씨와 기온을 표시합니다. 위치가 설정되어 있지 않거나 조회가 실패하면 상태를 표시합니다. 현재 날씨는 Open-Meteo의 현재 기온·날씨 코드로 가져오며 알람 구간 중 약 10분마다 갱신합니다. 날씨 음성 읽기에서 현재 도시를 제외하거나 음성 날씨 기능을 꺼도, 위치가 저장된 알람의 알림에는 현재 도시 날씨를 표시합니다.
