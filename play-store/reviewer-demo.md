# Play Console 권한 선언용 설명 초안

## 포그라운드 서비스 · mediaPlayback

Minute Voice는 사용자가 설정한 알람 시각 전후의 매분 안내를 한국어 음성으로 재생합니다. 목표 시각에는 사용자가 고른 알람 소리도 재생할 수 있습니다. 화면이 꺼져 있어도 음성을 끝까지 재생해야 하므로 알람이 울리는 동안 `mediaPlayback` 포그라운드 서비스를 실행하고 알림을 표시합니다. 재생이 끝나면 서비스를 종료합니다. 서비스를 지연하거나 중단하면 사용자가 정한 시각에 음성 안내를 듣지 못합니다.

## 정확한 알람

사용자가 알람 시각과 안내 전후 범위를 직접 지정합니다. 앱은 이 범위에서 정확히 1분 간격으로 음성을 안내해야 하므로 `SCHEDULE_EXACT_ALARM`을 사용합니다. 앱 안에서 사용자에게 시스템 권한 화면을 안내합니다.

## 검토자 시연 영상 구성

1. 앱 실행 → + 알람 추가 → 현재 시각에서 2분 뒤로 설정.
2. 알람 전 1분, 알람 후 0분, 반복 끄기, 제목 입력 → 저장.
3. 화면을 닫거나 다른 화면으로 이동 → 1분 전 음성과 지속 알림 표시.
4. 목표 시각의 음성 또는 선택한 알람 소리 재생 → 알림에서 ‘알람 중지’ 사용.

영상 링크는 Google Play 권한 선언 화면에서 요청할 때 입력한다. 공개 YouTube 미등록 동영상 또는 검토자가 접근 가능한 MP4 링크가 적합하다.
